# The Last of Us — Série

Projeto front-end inicial criado para apresentar uma página temática sobre a série *The Last of Us*.

A página exibe uma composição visual com imagens, logo, descrição e um carrossel controlado por botões. O projeto é mantido no GitHub como registro do início do aprendizado em desenvolvimento web.

## Tecnologias

- HTML
- CSS
- JavaScript
- Google Fonts

## Como executar

O projeto é estático e não possui etapa de build ou dependências instaláveis.

1. Clone o repositório.
2. Abra o arquivo `index.html` no navegador.

Para uma experiência de desenvolvimento local, também é possível usar uma extensão de servidor estático, como o Live Server do VS Code.

## Estrutura

```text
.
├── index.html
└── src/
    ├── css/
    ├── imagens/
    └── js/
```

## Funcionalidades

- Apresentação visual em tela cheia.
- Carrossel de imagens.
- Seleção da imagem por botões.
- Layout responsivo por folhas de estilo específicas.

## Limitações

- É um projeto front-end estático e não possui backend.
- Os links sociais exibidos na interface ainda são placeholders.
- Não há testes automatizados nem workflow de CI.
- O projeto não representa uma aplicação oficial da HBO, da PlayStation ou da franquia *The Last of Us*.

## Status

Projeto histórico de aprendizado. Não será republicado como aplicação principal.
